# Python File Analyser

A reusable Python module for analysing text files and retrieving basic text statistics.

Features

- Count alphabetic letters.
- Count total characters, including spaces.
- Count total words.
- Import and reuse functions in other Python programs.

Technologies Used

- Python 3

Functions

- "getLetters(file_path)"
- "getChars(file_path)"
- "getWordCount(file_path)"

Usage

import file_analyser

print(file_analyser.getLetters("sample.txt"))
print(file_analyser.getChars("sample.txt"))
print(file_analyser.getWordCount("sample.txt"))
